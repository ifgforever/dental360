Connect this computer

You only do this once per computer. The access key stays on this computer and lets this page save changes to your screen.

  1. Sign in to GitHub, then open New access key (fine-grained token).
  2. Name it Lobby screen and set Expiration to the longest option.
  3. Under Repository access pick Only select repositories and choose dental360.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.
